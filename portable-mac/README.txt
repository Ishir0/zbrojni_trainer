Zbrojni Trainer for Mac
=======================

1. Copy this folder to your Mac (or unzip Zbrojni-Trainer-Mac.zip from a USB drive).
2. Double-click Start.command. A Terminal window will open and your browser should open the app.
3. Keep the Terminal window open while you use the app. Press Control+C in that window to stop it.

If macOS blocks the launcher, Control-click Start.command, choose Open, then confirm Open.

Python 3 is required. If the launcher says it cannot find python3, install Python 3 and run it again.

Progress is saved by the browser on that Mac. It is separate from progress saved in another browser, on another device, or at a different website address. Use Settings in the app to export a backup before clearing browser data.

The app itself is local. Internet access is needed to open the linked official source documents.
